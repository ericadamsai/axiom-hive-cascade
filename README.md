# Axiom Hive Cascade

A lightweight full-stack TypeScript project (monorepo) with client, server, shared and drizzle schema.

## Quick start

### Prerequisites:
- Node.js 18+
- pnpm

### Install:

```bash
pnpm install
```

### Run development:

```bash
pnpm dev
```

### Build:

```bash
pnpm build
```

### Test:

```bash
pnpm test
```

## Repository layout

- client/ — frontend application
- server/ — backend application
- shared/ — shared types and utilities
- drizzle/ — database schema and migrations
- docs/ — project documentation
